# Cloud Computing Labs

Hands-on cloud learning repository focused on AWS fundamentals, architecture, security, and Infrastructure-as-Code as part of my Diploma in Software Development.

This repository follows the same structured documentation format used in my SysAdmin and Networking labs:

- Clear objectives
- Real-world scenarios
- Screenshot evidence
- Security and cost considerations
- Reflection and lessons learned

---

# Repository Structure

The `labs/` directory contains hands-on cloud exercises organized by platform and tooling:

```
labs/
├── linux/
├── networking/
└── windows/
```

Each lab includes:

- Objectives and scope  
- Environment details  
- Step-by-step tasks  
- Screenshots as evidence  
- Configuration files or Infrastructure-as-Code (where applicable)  
- Validation and testing  
- Security considerations  
- Cost-awareness considerations  
- Reflection and lessons learned
